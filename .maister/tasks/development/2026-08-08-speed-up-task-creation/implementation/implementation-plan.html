TL;DR

10 task groups: 4 gated Phase A groups (behavior-preserving app.ts split into 10 files), 4 independently-buildable Phase B component groups, 1 Phase B integration group, 1 final gap-review group. 59 steps total, ~49–59 manual verification checks — no automated test framework exists (see implementation/tdd-red-gate.md). Group 1 (extract logging.ts/types.ts/context.ts) is a hard gate that smoke-tests AMD cross-file imports before Groups 2–4 relocate the remaining 7 Phase-A files; Group 4's full-split smoke test is the hard gate before any Phase B group (5–9) may start. Phase B's four component groups build independently in parallel once Group 4 passes, converging in Group 9's orchestrator integration, then Group 10 closes gaps against the spec's 9 success criteria.

Key Decisions

Grouped Phase A by DAG tiers, not one group per filekeeps each group's smoke test meaningful (2–4 files/group) while isolating the AMD-import smoke test as its own gate
4 independent Phase B component groups (5–8), converged by Group 9mirrors the spec's own module-boundary dependency table exactly — no re-derivation
Live REST-endpoint capture placed as step 5.1hard implementation-time dependency (Core Requirement 9) surfaced early, not mid-implementation
Failure-aggregation threading (Req 12) lives in Group 9, not Group 5it threads results into orchestrator.ts's AddTasks, even though edits land in workItemCreation.ts (shared file, serialized 5→9)
"Write tests" replaced with "define manual verification checklist"project-wide adaptation — zero automated test framework exists

Open Questions / Risks

  • Groups 5–8 run concurrently once Group 4 passes, but Group 5 and Group 9 both touch workItemCreation.ts — already serialized via Group 9's dependency on Group 5.
  • Group 9 is the highest-risk single group (8 checks; concurrency rewrite + dispatch split + failure threading at once) — first place to look if Phase 9's Green Gate re-walk finds a regression.
  • Group 10 (this plan's Test Review & Gap Analysis) is distinct from, and precedes, the orchestrator's separate Phase 9 TDD Green Gate re-walk (tdd-red-gate.md) — do not conflate the two.
  • ~49–59 total manual checks is a large manual-only regression net, accepted given zero automated test framework exists (spec Requirement 17).
